## 2023-10-25 - Prevent double submission and improve screen reader alerts in standard HTML forms
**Learning:** Adding a simple inline JS to `onsubmit` for forms without AJAX (`onsubmit="this.querySelector('button[type=submit]').disabled = true; this.querySelector('button[type=submit]').textContent = 'Processing...';"`) is an extremely fast, zero-dependency way to provide immediate feedback to users and prevent duplicate POST requests on slow endpoints. Furthermore, adding `role="alert"` to Jinja2 conditional error boxes (`{% if error %}`) immediately surfaces server-side validation errors to screen readers on page load without extra aria live regions configuration.
**Action:** Always include this inline JS pattern for forms triggering expensive or synchronous server operations, and wrap all Jinja2 flashed error blocks in `role="alert"`.
